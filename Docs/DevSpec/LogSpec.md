# 日志与可观测性规范（LogSpec）

> 所属：VeritasQuant 开发规范 · 存放：`Docs/DevSpec/`
> 适用范围：VeritasQuant 全部代码模块与运行组件。

## 1. 结构化日志

- 程序入口和核心模块必须使用统一的结构化日志配置，不得使用零散的 `print` 充当运行日志。

## 2. 时间与上下文

- 日志时间字段统一使用 **UTC 的 `ts`**，并与当前运行的 `TsPrecision` 保持一致。
- 存在上下文时必须携带关联标识：`run_id`、`account_id`、`event_id`、`order_id`、`execution_id`、`alert_id` 等。

## 3. 职责边界

- 运行日志用于**诊断**，不能替代不可变事件、订单迁移、风险决定或账户账本等领域审计记录。

## 4. 敏感信息

- 禁止记录：密码、令牌、私钥、完整券商凭据和未脱敏个人信息。
- 高频事件应**聚合或采样**，避免日志洪峰与敏感信息扩散。
