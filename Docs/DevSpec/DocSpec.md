# 文档规范（DocSpec）

> 所属：FinvQuant 开发规范 · 存放：`Docs/DevSpec/`
> 适用范围：文档、界面文案与代码注释。
> Git 提交信息规范见 [`GitSpec.md`](GitSpec.md)。

## 1. 语言

- 默认使用**简体中文**编写文档、界面文案、注释和用户可见的技术说明；仅在代码标识符、事件名、配置键、第三方协议或术语准确性需要时使用英文。

## 2. 注释

- 开发时须为关键契约字段、参数校验和非直观操作补充简体中文注释。
- 避免对显而易见的赋值或语言惯例作重复说明。
- 代码注释默认使用简体中文，除非周边文件已有明确约定。

## 3. 文档组织（强制）

- **一个接口一个文档**：每个 API 接口必须独立成一篇文档文件，**不允许多个接口放到同一文件中描述**；文档命名与拆分规则见 [ApiSpec.md](ApiSpec.md) 第 7.2 节；
- **一个菜单一个文档**：每个业务菜单必须独立成一篇文档文件，**不允许多个业务菜单放到同一文档中描述**；文档命名与拆分规则见 [MenuSpec.md](MenuSpec.md) 第 2.2 节；
- **URL 查询参数统一小驼峰**：技术文档中描述的 URL 查询参数必须使用小驼峰（lowerCamelCase）风格，不得使用下划线风格；规则见 [ApiSpec.md](ApiSpec.md) 第 3 节；
- **编写技术文档时不允许擅自违反开发规范**：文档内容（含示例、接口路径、参数、错误码）必须与代码实现及本目录（`Docs/DevSpec/`）中的规范一致；规范冲突时以规范文档为准，并先修正规范或与规范维护者确认后再落文档。
