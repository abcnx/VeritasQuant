# 历史行情查询（QuoteQuery）— 菜单业务文档

> 所属：FinvQuant 前端菜单 · 存放：`Docs/Menu/HistoryQuote/HistoryQuoteQuery.md`
> 对应视图：`Web/src/views/Meta/Finv/Quote/History/HistoryQuoteQueryView.vue`
> 接口契约：见 [Docs/API/HistoryQuote/HistoryQuote.md](../../API/HistoryQuote/HistoryQuote.md)

## 1. 菜单入口

- **菜单位置**：左侧导航栏 → 历史行情 → 历史行情查询
- **菜单名称**：历史行情查询
- **菜单 key**：`quote-query`
- **菜单图标**：`mdi-chart-line`
- **URL 路由**：`/Meta/Finv/Quote/History/HistoryQuoteQuery`
- **对应视图组件**：`Web/src/views/Meta/Finv/Quote/History/HistoryQuoteQueryView.vue`

## 2. 业务功能概述

历史行情查询菜单为用户提供**按证券代码 + 日期区间查询分钟级 K 线**的能力，核心功能点：

| 功能 | 说明 |
|------|------|
| 分钟级 K 线查询 | 按证券代码 + 日期查询 1 分钟 K 线（周期目前仅支持 `Min`），**返回该日期区间全部记录**（不分页，适配 A 股/港股/美股/24h 电子盘单日数据量差异） |
| 证券代码下拉字典 | 证券代码框从 finv_security 字典下拉（`usc:security_name_cn` 格式），**同时保留手动输入**，默认值 `NVDA` |
| 多日回溯 | 支持 **1 日 / 5 日**切换，5 日模式返回截止日往前 5 天连续时间范围内的全部分钟级 K 线 |
| 日历点选日期 | 交易日期通过日历组件点选（**全中文界面**），不可晚于当天；自动转为 `yyyymmdd` 纯数字提交 |
| 富途风格 K 线 | 红涨绿跌配色 + MA5/MA10/MA20/MA30 均线 + BOLL 布林带 + 成交量副图，悬停查看明细 |
| 拖拽 / 滚轮平移 | 滚轮缩放、鼠标拖拽平移时间窗（dataZoom inside），价格轴与成交量轴联动，替代传统分页翻页 |
| 图表自适应 | 导航栏折叠/展开、窗口缩放时图表自动适配容器宽度（ResizeObserver + window resize） |

## 3. 操作流程（用户视角）

```
输入/选择证券代码（默认 NVDA）→ 日历点选交易日期 → 选择周期（Min）→ 切换 1日/5日
    → 自动查询并渲染 K 线图（悬停看明细、滚轮缩放、拖拽平移）
```

详细步骤：

1. **输入/选择证券代码**：支持下拉选择（选项格式 `usc:security_name_cn`，如 `GCMain:黄金期货主连`），也支持直接手动输入。默认值 `NVDA`。
2. **点选交易日期**：点击日期输入框弹出**中文日历**（年月、星期均为简体中文），选择日期（最大为当天）。多日模式（5 日）时该日期作为**回溯截止日**。选中后输入框显示 `yyyy-MM-dd`，提交时转为 `yyyymmdd` 纯数字（如 `20260716`）。
3. **选择周期**：目前仅提供「1分（Min）」选项。
4. **切换 1 日 / 5 日**：按钮组切换回溯天数（1 日 / 5 日自然日）。
5. **自动查询**：切换证券 / 日期 / 天数 / 周期后**自动触发查询**并渲染图表（无需手动点「查询」；表单「查询」按钮仍保留，作为手动刷新）。
6. **拖拽 / 缩放查看**：鼠标滚轮缩放、左键拖拽平移时间窗；无分页翻页（返回全部记录一次性渲染）。

> 提示：切换查询条件后**自动触发查询**（原实现需手动点击「查询」）；返回全部记录后**无分页**，通过滚轮/拖拽平移查看。

## 4. 前端处理逻辑

### 4.1 查询参数校验

| 校验项 | 规则 | 失败提示 |
|--------|------|----------|
| 证券代码 | 非空（去除首尾空格） | `证券代码不能为空` |
| 交易日期 | 必须通过日历选择，格式 `yyyymmdd`（8 位纯数字） | `请通过日历选择交易日期` |

### 4.2 证券代码下拉字典

- 页面加载时请求 `GET /API/V1/Meta/Finv/Quant/Metadata/Security/Options` 获取**启用状态**证券列表（`usc` + `security_name_cn`）。
- 下拉选项展示格式：`usc:security_name_cn`（如 `GCMain:黄金期货主连`）；选中后自动回填证券名称 `secu_name`。
- 字典加载失败不阻塞使用（仍可手动输入证券代码查询）。

### 4.3 请求与响应处理

- **请求**：`GET /API/V1/Meta/Finv/Quant/Quote/History/QuoteQuery`，Query 参数如下：

| 参数 | 取值 | 说明 |
|------|------|------|
| `secuCode` | 用户输入 / 下拉选中的 usc | 证券代码（key） |
| `secuName` | 下拉选中的 security_name_cn | 证券名称（可选，便于确认证券是否选对） |
| `date` | `yyyymmdd` | 交易日期（回溯截止日），**纯 8 位数字** |
| `period` | `Min` | 周期 |
| `days` | `1` / `5` | 回溯自然日数 |

> 前端传 `date`+`days`，服务端内部换算为 ts 时间范围（UTC 秒）查询；也支持直接传 `startTs`/`endTs`（URL 查询参数遵循小驼峰，见 ApiSpec §3）。

- **响应处理**：
  - `body.code !== 0` → 展示 `body.message` 为错误提示。
  - 请求异常（网络失败）→ 提示 `网络错误：无法连接服务端`。
  - 成功 → 保存 `bars` 与 `total`，生成摘要提示，渲染图表；无数据时清空图表。

- **摘要提示格式**（snackbar 吐司，3 秒自动消失）：
  `{证券代码}（{证券名称}） {日期范围} {周期} · {N}日 · 共 {total} 根`
  - 单日模式日期范围直接显示交易日期；5 日模式显示首尾 K 线的 `MMDD-MMDD` 区间。

### 4.4 K 线渲染逻辑（ECharts）

- **配色**：红涨绿跌（富途牛牛风格）——上涨 `#ef232a`，下跌 `#14b143`；黑色主题背景 `#1e1e1e`。
- **K 线序列**：每根蜡烛数据 `[open, close, low, high]`；缺失价格视为 0（不参与展示）。
- **均线**：MA5/MA10/MA20/MA30 滑动窗口计算，窗口内存在缺失值输出 null（避免断点被错误填充）。
- **布林带**：BOLL（20 周期，2 倍标准差）上/中/下轨，图例第二行可独立显隐。
- **成交量**：副图柱状，按涨跌红绿着色。
- **dataZoom**：滚轮 / 拖拽缩放与平移，价格轴与成交量轴联动。
- **x 轴刻度**：1 日模式整点标时刻；5 日模式 0 点标日期、4/8/12/16/20 点标时刻。
- **图表自适应**：`ResizeObserver` 监听图表容器 + `window resize` 兜底，导航栏折叠/展开时 `chart.resize()`。

## 5. 注意事项

- 日期组件全局使用简体中文（Vuetify locale `zhHans`）：年份、月份、星期均按中国习惯展示。
- `date` 参数**始终为 8 位纯数字**（如 `20260716`）；组件本身也只允许选择日期（无时间维度）。
- 查询返回该日期区间**全部记录**（不分页）：单日如 GCMain 约 2181 根、5 日约数千根，一次性渲染；数据量大时靠 dataZoom 缩放/平移查看。
- 证券下拉字典只包含启用状态证券；如需更多证券，先在「规范证券信息维护」菜单中维护 finv_security 字典。
