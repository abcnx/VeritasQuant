# P1-032 崩溃恢复与重复重放验证证据

固定随机种子 `20260801` 下，对 inbox、账本、订单、控制、checkpoint 和 outbox 的前后共 12 个提交边界逐一注入受控崩溃。每个场景均会重启并重放同一输入：提交前崩溃执行一次重放，outbox 提交后崩溃不再重复提交。

验证结果要求所有场景最终具有五条领域事实、一条 outbox 消息、相同的事实哈希和投影哈希；控制事实的内容哈希固定为 `c` 重复 64 次，证明恢复过程不放宽既有控制。投影删除后由不可变事实再次重建，哈希保持一致。

```powershell
python3 -m pytest tests\unit\core\test_recovery.py -q
```
