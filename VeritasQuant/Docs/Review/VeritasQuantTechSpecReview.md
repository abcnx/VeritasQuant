## 4. 详细 Findings

### ~~R-001 [已关闭] 运行级时间精度与版本化完整排序键~~

**依据**：`VeritasQuantTechSpec.md:63`、`:73`、`:232`、`:291`。

**处理结果**：权威技术方案已明确 `TsPrecision` 是运行级统一配置，默认 `Second`，需要毫秒时整个运行使用 `Millisecond`，禁止隐式降精度。事件使用版本化排序键 `ts + phase + priority + source_rank + source_sequence + event_id`；`phase` 固定六步因果顺序，诊断时间使用独立高精度字段且不参与因果排序。

**验证要求**：后续实现仍需为 `Second` 和 `Millisecond` 分别建立跨来源同值、派生阶段和 `event_id` 最终决胜的回归基准。该要求已进入技术方案第 15 章。

### ~~R-002 [已关闭] 交易主链路崩溃一致性、inbox/outbox 和恢复边界~~

**依据**：`VeritasQuantTechSpec.md` 第 6.1、6.2、8.1、8.6 和 12.2 节。

**处理结果**：事件循环已改为各阶段提交，不再在末尾补写持久化。技术方案定义了标准事件、执行回报、订单审批、交易控制及券商结果的 inbox 幂等键和原子事务表；订单、账本、风险决定、活动控制、checkpoint 与 outbox 的提交边界已经闭合。券商副作用使用稳定 `command_id` 和至少一次投递，未知结果必须先对账。快照明确为可删除重建的加速投影，并新增 `VeritasQuantCrashRecoverySequence.svg` 固化恢复顺序和恢复交易门禁。

**验证要求**：实现阶段须在每个数据库提交和 outbox 发布边界、券商发送结果未知及快照写入期间执行崩溃注入；恢复后订单、账本、控制和 outbox 无丢失、无重复，投影可从事实序列重建。该要求已进入技术方案第 12.2 节。

### ~~R-003 [已关闭] 可编辑 Python 策略的技术隔离~~

**依据**：`VeritasQuantTechSpec.md` 第 4.5、6、9、10 和 12.2 节。

**处理结果**：所有可编辑 Python 策略均按不可信代码处理，并按 `strategy_id + strategy_version + account_id` 建立独立隔离域。方案已经定义只读序列化 IPC、默认拒绝 API、文件/环境/网络/进程/系统调用边界、确定性时钟与随机源、首期 CPU/内存/文件描述符/回调/IPC/订单意图配额，以及回测和在线模式不同的超时处置。仿真和实盘必须使用具备操作系统隔离的容器或受限环境；实盘版本还须冻结源码、依赖、解释器、镜像摘要和审批记录。

**验证要求**：实现阶段须通过未来数据、文件、环境变量、网络、数据库、危险导入、子进程、系统时间/熵、死循环、内存耗尽、超量 IPC 和跨账户访问探针；违规输出不得形成有效订单。该要求已进入技术方案第 12.2 节。

### ~~R-004 [已关闭] 风控引擎与预警策略求值器的决策权限~~

**依据**：`VeritasQuantTechSpec.md` 第 3、8.1、8.2、8.3 和 12.2 节。

**处理结果**：`AlertPolicyEngine` 已固化为 RiskEngine 进程内的纯规则求值器，只返回候选动作、命中规则和证据，不访问总线、数据库、OMS 或券商。只有 RiskEngine 可以结合账户、持仓、订单、策略状态、人工请求和活动控制，发布 `RiskDecisionEvent` 与 `TradingControlEvent`。方案新增发布权限表，并同步总体架构图和预警处理链路；通知路由继续独立。

**验证要求**：事件 Schema 注册和持久化端必须拒绝非 RiskEngine 生产者写入风险决定或交易控制；测试须验证内部求值器无副作用、通知确认不会解除控制、旧控制版本不会覆盖更严格的活动控制。

## 7. 已确认的方案优点

- 行情事件 T 的六步处理顺序明确，能作为防前视测试的基础。
- `RiskSignal`、`AlertEvent`、`RiskEngine`、交易控制与通知职责分离方向正确。
- 成交与部分成交要求原子更新订单、资金和持仓，避免绩效与账户状态脱节。
- 多账户使用显式 `account_id`，并禁止默认跨账户资金共享。
- 理想和真实撮合双轨有助于区分信号质量与执行可行性。
- 结构化日志明确不能替代领域审计，安全边界合理。
- `src` 布局、单 wheel、包内入口和根级部署清单的边界已闭合，可作为后续命令实现与部署的固定基线。
