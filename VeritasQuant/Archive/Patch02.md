## 补充内容：GUI界面、策略编写与双轨回报率

### 一、图形用户界面（GUI）详细设计

VeritasQuant提供基于 **Streamlit** 的桌面级 Web 应用，通过直观的图形界面完成策略开发、回测配置、执行监控与绩效分析。GUI 后端通过 FastAPI 与核心引擎通信，所有操作均可脱离命令行独立运行。

#### 1.1 主界面布局
- **左侧导航栏**：策略管理、回测中心、结果分析、实时监控、系统设置。
- **顶部状态栏**：显示当前运行模式（回测/模拟/实盘）、引擎状态、最新事件时间。

#### 1.2 策略管理页面
- **策略列表**：以卡片形式展示所有已保存策略，包含名称、版本、创建时间、简短描述。
- **操作按钮**：新建、编辑、复制、删除、导出/导入（支持 Python 文件或 YAML 包）。
- **策略编辑器**（点击编辑进入）：
  - **代码模式**：内嵌 Monaco Editor（Ace 升级版），提供 Python 语法高亮、智能提示（基于 `BaseStrategy` 的可用方法和指标库），支持错误实时检查。
  - **可视化模式**：拖拽式画布，左侧为指标/条件/动作组件库，中间为流程图式策略编排区，右侧为参数配置面板。
  - **YAML 模式**：直接编辑结构化策略文件，带语法校验和自动补全。

#### 1.3 可视化策略构建器（重点）
面向非编程用户或快速原型设计，核心组件包括：
- **数据组件**：选择标的、周期（分钟/日合成）。
- **指标组件**：SMA、EMA、MACD、RSI、布林带等，从面板拖入画布，连接参数线。
- **条件组件**：大于、小于、交叉、金叉死叉、连续 N 周期等。
- **逻辑组件**：AND、OR、NOT，支持嵌套。
- **动作组件**：买入、卖出、加仓、减仓，可设置下单类型（市价/限价）、价格偏移、仓位计算方式（固定手数、百分比、凯利）。
- **风控组件**：止损点、止盈点、最大持仓、单日亏损限额。
- **画布操作**：连线即建立逻辑流，所有组件可折叠/展开，支持缩略图导航。构建完成后，系统自动生成等效 Python 策略类或 YAML 定义，并存入策略库，后续可在代码模式中二次修改。

#### 1.4 回测中心
- **策略选择**：从列表勾选待回测策略，支持多策略并行对比。
- **数据配置**：选择行情文件目录、日期范围、初始资金、基础币种。
- **撮合模式**：
  - **理想模式**（快速评估）：开关打开即启用简化撮合（无延迟、100% 成交、零滑点）。
  - **真实模式**（实盘模拟）：开启后显示详细参数面板——延迟分钟数滑块、成交概率模型下拉（固定/成交量比例/历史分布）、滑点设置、超时时间等。
- **执行控制**：运行、暂停、停止按钮，回测过程中实时绘制权益曲线和持仓变动。

#### 1.5 结果分析页面
- **概览仪表盘**：理想 vs 真实收益对比卡片、夏普比率、最大回撤、胜率、盈亏比。
- **详细图表**：累计收益曲线、回撤序列、月度收益率热力图、逐笔成交气泡图。
- **成交分析**：未成交订单统计、部分成交比例、平均滑点、延迟分布直方图。
- **参数敏感性**：当使用真实模式时，可在线调整任一撮合参数，即时重算绩效，生成敏感度曲线。
- **报告导出**：PDF/HTML 格式的完整回测报告。

### 二、结构化策略编写指南（扩展）

VeritasQ 定义了一套**策略描述语言（轻量 DSL）**，使策略逻辑可以独立于 Python 代码，以 YAML 或 JSON 形式存储，从而便于 GUI 生成、版本对比和审计。

#### 2.1 DSL 结构说明
一个完整的结构化策略包含四个部分：

```yaml
strategy:
  name: "DualMA_Limit"
  version: "1.2"
  description: "双均线限价单策略"

universe:
  - symbol: "518880"
    market: "ETF_CN"
  - symbol: "AU8830"
    market: "FUTURE_CN"

variables:                    # 用户自定义变量
  - name: short_period
    value: 20
  - name: long_period
    value: 60

indicators:                   # 指标定义
  - id: ma_short
    type: SMA
    inputs: close
    params:
      period: short_period
  - id: ma_long
    type: SMA
    inputs: close
    params:
      period: long_period

signals:                      # 信号条件
  buy: "cross(ma_short, ma_long) == 'above' AND position == 0"
  sell: "cross(ma_short, ma_long) == 'below' AND position > 0"

execution:                    # 下单规则
  buy_order:
    type: limit
    price: "close * 0.998"
    size: "capital * 0.95 / close"
    timeout: 60               # 分钟
  sell_order:
    type: limit
    price: "close * 1.002"
    size: "position"
    timeout: 60

risk:                         # 独立风控（可被全局覆盖）
  max_positions: 1
  stop_loss: 0.03
  daily_loss_limit: 0.05
```

#### 2.2 支持的指标与函数
- **内置指标**：`SMA`, `EMA`, `MACD`, `RSI`, `Bollinger`, `ATR`, `VWAP`, `ADX` 等。
- **序列函数**：`cross(a,b)`、`above(a,b)`、`below(a,b)`、`max(a,n)`、`min(a,n)`、`delta(a,n)`。
- **上下文变量**：`position`、`capital`、`close`、`open`、`high`、`low`、`volume`、`bar_count`。

#### 2.3 策略编写三模式对比
| 模式        | 适用人群       | 灵活度 | 可读性 | 版本追踪                |
| ----------- | -------------- | ------ | ------ | ----------------------- |
| Python 代码 | 专业量化开发者 | 最高   | 需文档 | Git 管理                |
| YAML 结构化 | 半技术分析师   | 高     | 极强   | 可 diff                 |
| GUI 可视化  | 交易员/新手    | 中高   | 直观   | 自动生成 Python 或 YAML |

三种模式输出可相互转换，用户可从 GUI 生成 YAML，再交由开发者用 Python 优化复杂逻辑。平台会校验转换后的策略在回测中表现是否与原始定义一致（回归测试）。

### 三、理想化年化收益率 vs 真实回报率

VeritasQ 将策略绩效评估明确拆分为两个层级，帮助用户清醒认知策略的理论上限与现实摩擦。

#### 3.1 理想化年化收益率回测
- **目的**：在零摩擦市场中检验策略的交易逻辑，获得最大可能收益，用于早期筛选与参数搜索。
- **撮合假设**：
  - 市价单：下一分钟开盘价 **100% 成交**。
  - 限价单：当分钟价格触及即 **100% 成交**，成交价等于挂单价。
  - 无延迟、无滑点（除用户配置的固定手续费外）。
  - 无视涨跌停、停牌等特殊情况。
- **计算指标**：年化收益率、年化波动率、最大回撤、Calmar 比率等。
- **配置方式**：在 GUI 回测中心关闭“真实模式”开关，或在配置中设置 `execution.mode: ideal`。
- **局限**：此模式下的收益在实盘中几乎不可能实现，仅作策略逻辑有效性的“天花板”参考。

#### 3.2 真实回报率验证
- **目的**：模拟实盘中所有不可忽略的微观结构摩擦，得出更贴近真实交易的期望收益。
- **撮合模型**：启用完整的**多层级概率撮合**（参见方案第8章），包括：
  - 订单提交延迟（`delay_bars` ≥ 1）；
  - 限价单队列成交概率（可配为固定概率、成交量比例、或历史分布采样）；
  - 部分成交（受 `max_volume_ratio` 限制）；
  - 滑点与冲击成本（固定跳数 + 波动率比例）；
  - 订单超时自动撤单，产生 `CancelEvent`；
  - 涨跌停/停牌导致订单拒绝。
- **策略响应**：策略必须处理 `PartialFill` 和 `CancelEvent`，否则可能在回测中出现未预期仓位，导致绩效失真。
- **配置方式**：开启“真实模式”，填写详细参数。建议至少使用悲观的默认参数进行压力测试。
- **意义**：只有在真实模式回测和后续模拟盘中仍保持正期望的策略，才具备进入实盘的资格。

#### 3.3 双轨对比与反馈循环
在结果分析页面，系统会自动将同一策略的**理想收益曲线**与**真实收益曲线**叠加显示，并标注摩擦成本占比（例如“真实收益仅为理想值的 62%”）。用户可据此调整策略（如放宽挂单价格、缩短超时时间）或调整对流动性的预期。进入仿真和实盘阶段后，真实成交数据会回流校准撮合参数，使“真实模式”的模拟结果越来越接近实际交易绩效，形成完善的策略评估闭环。
